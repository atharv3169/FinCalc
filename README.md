# FinCalc

FinCalc is a Python command-line financial calculator. It supports compound interest, loan EMI, investment CAGR, present value, loan amortization CSV export, and optional calculation history.

## Run

Requires Python 3.10 or later.

```bash
python fincalc.py
```

For automated tests, install `pytest` and run:

```bash
python -m pip install pytest
python -m pytest -v
```
